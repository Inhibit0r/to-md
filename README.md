# to-md

Любой файл → markdown. Медиа расшифровывает whisper локально, документы конвертирует anydoc, фотографии распознаёт зрение модели. Дальше по тексту работает скилл `/to-md:convert`: собирает summary для записей и сводный файл для снимков.

## Что получается

Снимок задачи с доски → `out/raw/IMG_4471.md`:

```markdown
---
source: "IMG_4471.jpg"
date: 2026-08-14
type: задача
---

## Задача 14

Тело массой m = 2 кг движется по окружности радиусом R = 0,5 м
с постоянной по модулю скоростью v = 4 м/с.

Найти: модуль ускорения и силу натяжения нити в верхней точке.

---
> Не перенесено: логотип вуза, номер слайда «7/23», край соседней страницы.
```

Последняя строка — не украшение. Модель вправе **не переносить** содержимое, но не вправе его переписывать: всё, что попало в файл, стоит там как на снимке, а всё выброшенное перечислено. Удаление, которое видно, можно проверить. Нечитаемое место помечается `[неразборчиво]`, и файлы с двумя метками и больше уходят на второй проход автоматически.

У записей та же дисциплина: каждый пункт summary несёт таймкод `[MM:SS]`, у документов — цитату. Пункт без якоря в файл не попадает.

## Требования

**Python 3.10 или новее** — нижняя граница `firecrawl-anydoc`. Всё остальное ставит `/to-md:setup`.

## Установка

Claude Code:

```
/plugin marketplace add Inhibit0r/to-md
/plugin install to-md@to-md
/to-md:setup
```

Codex:

```bash
codex plugin marketplace add Inhibit0r/to-md
codex plugin add to-md@to-md
```

Обновление — `/plugin marketplace update to-md` в Claude Code, `codex plugin marketplace` в Codex.

## Использование

Положить файлы в `in/` и вызвать `/to-md:convert`. Результат — в `out/`: пофайловые md в `out/raw/`, summary записей в `out/`, задачи со снимков одной пачкой в `out/задачи.md`.

| Класс | Расширения | Чем |
|---|---|---|
| Медиа | mp4, mov, mkv, webm, avi, m4v, mp3, wav, m4a | whisper-ctranslate2, large-v3-turbo |
| Документы | pdf, doc(x/m), ppt(x/m), pps(x/m), pot, xls(x/m/b), odt, ods, odp, rtf, epub, csv | anydoc |
| Фото | jpg, jpeg, png, webp, bmp, tif, tiff, heic | зрение модели, два прохода |

txt, md, html, json, xml, yaml конвертации не требуют — агент читает их напрямую.

Скрипт вызывается и руками:

```bash
python scripts/to_md.py in --out out --hotwords "Чжанцзяцзе, Тяньмэнь."   # ТОЧКА В КОНЦЕ обязательна
python scripts/to_md.py --doctor            # что установлено на этой машине
python scripts/to_md.py --escalate out/raw  # снимки, которые стоит перечитать
python scripts/to_md.py --collect out       # пересобрать out/задачи.md
python scripts/to_md.py --selftest
```

## Что стоит знать

- **Медиа и документы бесплатны, фотографии — нет.** Whisper и anydoc считают локально, а снимки идут через зрение модели, и нечитаемые уходят на второй проход. Пачка из двадцати пяти снимков — это порядка 120 тысяч входных токенов. Расшифровка часовой записи не стоит ничего, кроме электричества.
- **`--hotwords` без точки на конце ломает пунктуацию.** Модель копирует стиль подсказки: список без знаков препинания → транскрипт без знаков препинания.
- **Реестр `out/.state.json` ключуется по содержимому файла.** Переименовал — не пересчитается. Стёр md — пересчитается. Выбросить насовсем — убрать исходник из `in/`.
- **Совпали основы имён** (`отчёт.pdf` и `отчёт.docx`) — оба получают расширение в имени md: `отчёт-pdf.md`, `отчёт-docx.md`. Правило «один входной файл → один md» держится всегда.
- **Сводный `out/задачи.md` пересобирается целиком.** Правки вносите в `out/raw/`.
- **Скорость.** Windows с NVIDIA: замер x27 к реальному времени. macOS: только процессор — у CTranslate2 нет бэкенда Metal, порядок замерим на первом прогоне.
- **Веса** `large-v3-turbo` (≈1,5 ГБ) лежат в папке данных плагина, а если её нет — в `~/.to-md/models/`; обновление плагина их не стирает. Точный путь показывает `--doctor` полем `data`. Загрузка виснет на нуле байт — это xet-загрузчик HuggingFace: он отключается сам, прокси при необходимости задаётся `TO_MD_PROXY`.
- **pdf без текстового слоя** даёт «текста нет, вероятно скан» — сфотографируйте или отсканируйте его, ветка фото такое читает.
- **Снимок монитора дешевле заменить скриншотом** — резче и без муара.
- **Текст, вшитый в кадр видео, не распознаётся** — берётся только звуковая дорожка.
- `in/`, `out/` и `models/` под git-игнором.

## Файлы

- `scripts/to_md.py` — диспетчер, реестр, план батчей, `--doctor`, `--escalate`, `--collect`, `--selftest`
- `scripts/fetch_plaud.py` — записи с диктофона Plaud в `in/`
- `skills/convert/` — скилл конвертации и два контракта для субагентов
- `skills/setup/` — установщик зависимостей

## Безопасность и лицензия

Плагин читает недоверенный материал и спавнит субагентов с правом писать файлы — что это значит на практике, написано в [SECURITY.md](SECURITY.md), там же адрес для приватных сообщений о проблемах.
