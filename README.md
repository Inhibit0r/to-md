**Один плагин переводит в markdown то, с чем агент иначе работает дорого и плохо.** Записи расшифровывает whisper на вашей машине, документы конвертирует anydoc, фотографии читает зрение модели в два прохода. Скилл `/to-md:convert` раскладывает результат по файлам, собирает summary для записей и сводный файл для снимков.

Задумывался ради одного сценария: снимок задачи с лекции стоит до 4 800 токенов при каждой пересылке, распознанное условие — пару сотен. Один раз перевести в текст, дальше решать дёшево.

```
/plugin marketplace add Inhibit0r/to-md
/plugin install to-md@to-md
/to-md:setup
```

Нужен Python 3.10 или новее. Остальное `/to-md:setup` подберёт под вашу систему сам: на Windows с NVIDIA поставит CUDA-библиотеки, на Маке не станет.

## Форматы

Записи: mp4, mov, mkv, webm, avi, m4v, mp3, wav, m4a.

Документы: pdf, doc, docx, docm, ppt, pptx, pptm, pps, ppsx, pot, xls, xlsx, xlsm, xlsb, odt, ods, odp, rtf, epub, csv.

Фотографии: jpg, jpeg, png, webp, bmp, tif, tiff, heic.

txt, md, html, json, xml и yaml плагин не трогает — агент читает их напрямую и получает об этом строку в отчёте.

## Что на выходе

Снимок задачи с доски даёт `out/raw/IMG_4471.md`:

```markdown
---
source: "IMG_4471.jpg"
date: 2026-08-14
type: задача
---

## Задача 14

Тело массой m = 2 кг движется по окружности радиусом R = 0,5 м
с постоянной по модулю скоростью v = 4 м/с.

Найти: модуль ускорения и силу натяжения нити в верхней точке.

---
> Не перенесено: логотип вуза, номер слайда «7/23», край соседней страницы.
```

Модель вправе не переносить содержимое, но не вправе его переписывать: в файле оно стоит как в источнике, а выброшенное перечислено последней строкой. Нечитаемое помечается `[неразборчиво]`, и снимки с двумя метками уходят на второй проход — моделью посильнее, с разрешением кадрировать.

У записей и документов работает то же правило через якоря: пункт summary несёт таймкод `[MM:SS]` или цитату, иначе он не пишется.

## Что дальше делать с результатом

Файлы ложатся в `out/raw/` по одному на источник, summary записей — в `out/`, задачи со снимков — одной пачкой в `out/задачи.md`. Реестр `out/.state.json` ключуется по содержимому файла, поэтому:

- переименовали исходник — он не пересчитается;
- дописали в папку ещё десять снимков — обработаются только они;
- вышел кривой результат — сотрите его md, следующий прогон переделает;
- нужно выбросить совсем — уберите исходник из `in/`.

Скилл делает всё сам, но скрипт работает и руками:

```bash
python scripts/to_md.py in --out out --hotwords "Чжанцзяцзе, Тяньмэнь."   # точка в конце обязательна
python scripts/to_md.py --doctor            # что установлено на этой машине
python scripts/to_md.py --escalate out/raw  # снимки, которые стоит перечитать
python scripts/to_md.py --collect out       # пересобрать сводный файл
python scripts/to_md.py --selftest
```

## Ограничения

Записи и документы считаются локально и не стоят ничего. Фотографии идут через модель: пачка из двадцати пяти снимков — это примерно 120 тысяч входных токенов, и часть из них уйдёт на второй проход.

На Маке whisper считает процессором. У CTranslate2 нет бэкенда Metal, видеокарту Apple он не задействует — это свойство движка, а не настройка. На Windows с NVIDIA замер дал x27 к реальному времени.

`--hotwords` без точки на конце ломает пунктуацию: модель копирует стиль подсказки, и список без знаков препинания даёт транскрипт без знаков препинания.

Веса `large-v3-turbo` весят около полутора гигабайт, скачиваются один раз и переживают обновление плагина. Текст, вшитый в кадр видео, не распознаётся — берётся звуковая дорожка.

> [!IMPORTANT]
> Плагин читает недоверенный материал и запускает субагентов с правом писать файлы. Текст на чужом снимке может выглядеть как инструкция агенту; контракты распознавания говорят субагенту обращаться с содержимым как с материалом, но это смягчение, а не гарантия. Подробности и приватный канал для сообщений — в [SECURITY.md](SECURITY.md).

## Как устроено

`scripts/to_md.py` держит всю детерминированную часть: ветвление по расширению, реестр, разбиение снимков на батчи, подсчёт меток, решение об эскалации. Что считается `if`-ом, модель не решает.

`skills/convert/` — скилл конвертации и два контракта, которые субагенты читают дословно, а не в пересказе основной сессии. `skills/setup/` — установщик, собирающий список пакетов по выводу `--doctor`.

Codex ставит тот же плагин из терминала:

```bash
codex plugin marketplace add Inhibit0r/to-md
codex plugin add to-md@to-md
```
