**Один плагин переводит в markdown то, с чем агент иначе работает дорого и плохо.** Записи расшифровывает whisper на вашей машине, документы конвертирует anydoc, фотографии читает модель. Сложные снимки она разбирает вторым проходом. Скилл `convert` раскладывает результат по файлам, собирает summary для записей и сводный файл для снимков.

Задумывался ради одного сценария: снимок задачи с лекции стоит до 4 800 токенов при каждой пересылке, распознанное условие — пару сотен. Один раз перевести в текст, дальше решать дёшево.

**Codex.** Добавьте плагин из `main` в терминале.

```bash
codex plugin marketplace add Inhibit0r/to-md --ref main
codex plugin add to-md@to-md
```

В новом сеансе вызовите `$to-md:setup`. Когда окружение готово, дайте путь или ссылку, например `$to-md:convert Конспект.pdf`.

**Claude Code.** Добавьте плагин в чате.

```text
/plugin marketplace add Inhibit0r/to-md
/plugin install to-md@to-md
```

В новом сеансе или после `/reload-plugins` вызовите `/to-md:setup`. Для того же файла команда в Claude Code — `/to-md:convert Конспект.pdf`. В обоих клиентах без пути навык берёт `in/` из текущей рабочей папки.

Для запуска установщика нужен Python 3.10+. `setup` собирает отдельное окружение Python 3.12 в каталоге данных. На Windows с NVIDIA дополнительно ставятся CUDA-библиотеки.

Оба клиента по умолчанию используют один каталог данных. На macOS и Linux это `${XDG_DATA_HOME:-$HOME/.local/share}/to-md`, на Windows — `%LOCALAPPDATA%\to-md`. `--data` задаёт путь на один запуск, `TO_MD_DATA` — для всех запусков в этом окружении. Пока нейтральный каталог не создан, скрипт подхватывает прежнее хранилище `~/.to-md` или каталог из `CLAUDE_PLUGIN_DATA`, если там есть окружение или веса.

При переносе сначала скопируйте `models/` из прежнего каталога, затем запустите `--bootstrap --data <новый каталог>`: у Python-окружения абсолютные пути, поэтому его нужно собрать заново. Проверьте `--doctor` и распознавание тестовой записи. Прежний каталог можно указать через `--data`, если нужен возврат.

## Форматы

Записи: mp4, mov, mkv, webm, avi, m4v, mp3, wav, m4a, а также ogg, oga и opus — голосовые Telegram. Ссылки: YouTube, Instagram, TikTok, VK и всё, что знает yt-dlp, — дорожка скачивается в `in/` и идёт тем же путём, ffmpeg не нужен.

Документы: pdf, doc, docx, docm, ppt, pptx, pptm, pps, ppsx, ppsm, pot, xls, xlsx, xlsm, xlsb, odt, ods, odp, rtf, epub, csv.

Фотографии: jpg, jpeg, png, webp, bmp, tif, tiff, heic.

txt, md, html, htm, json, xml, yaml и yml агент читает напрямую. Скрипт перечисляет их в отчёте.

## Что на выходе

Снимок задачи с доски даёт `out/raw/IMG_4471.md`:

```markdown
---
source: "IMG_4471.jpg"
date: 2026-08-14
type: задача
---

## Задача 14

Тело массой m = 2 кг движется по окружности радиусом R = 0,5 м
с постоянной по модулю скоростью v = 4 м/с.

Найти: модуль ускорения и силу натяжения нити в верхней точке.

---
> Не перенесено: логотип вуза, номер слайда «7/23», край соседней страницы.
```

Модель вправе не переносить содержимое, но не вправе его переписывать: в файле оно стоит как в источнике, а выброшенное перечислено последней строкой. Нечитаемое помечается `[неразборчиво]`. Если таких меток две или больше, агент перечитывает снимок и может увеличить спорный фрагмент.

У записи каждый пункт summary опирается на таймкод `[MM:SS]` или цитату из расшифровки.

## Что дальше делать с результатом

Документ готов сразу, поэтому его md ложится рядом с исходником: `Домашнее задание 1.docx` → `Домашнее задание 1.md` в той же папке, без `out/`. Если имя занято чужим md, выход получит имя `Домашнее задание 1-docx.md`. Заняты оба имени — скрипт пропустит документ и укажет причину. Правили исходник позже md — следующий прогон его переделает.

У записей и снимков есть черновик и чистовик, им нужна мастерская: пофайловые md — в `out/raw/`, summary записей — в `out/`, задачи со снимков — одной пачкой в `out/задачи.md`. Реестр `out/.state.json` ключуется по содержимому файла, поэтому:

- переименовали исходник — он не пересчитается;
- дописали в папку ещё десять снимков — обработаются только они;
- вышел кривой результат — сотрите его md, следующий прогон переделает;
- нужно убрать снимок из сводного файла — перенесите сам снимок и его md из рабочих папок, затем пересоберите `задачи.md`.

Если обработка записи прервалась после расшифровки, снова вызовите `convert` для той же записи. Навык найдёт готовый текст и допишет недостающую сводку.

Скрипт можно запустить и руками из корня копии плагина:

```bash
python scripts/to_md.py in --out out              # дефолт: VAD включён, hotwords выключены
python scripts/to_md.py "<url>" --out out --lang en  # ссылка: файл ляжет в in/ и обработается
python scripts/to_md.py in --out out --vad False  # если дефолтный прогон теряет куски
python scripts/to_md.py --doctor                  # что установлено на этой машине
python scripts/to_md.py --escalate out/raw        # снимки, которые стоит перечитать
python scripts/to_md.py --collect out --in in      # пересобрать сводный файл, сверить исходные снимки
python scripts/to_md.py --selftest
```

В другой агентской среде возьмите полную копию репозитория. Дайте агенту [инструкцию convert](skills/convert/SKILL.md) и путь к материалу. Скрипт конвертирует документы, расшифровывает записи и выдаёт план для снимков. Снимки читает агент со зрением, сводки составляет агент по расшифровке.

## Ограничения

Расшифровка записей и конвертация документов идут локально. Чтение фотографий и подготовка сводок расходуют токены модели. Ориентир для пачки из двадцати пяти снимков — около 120 тысяч входных токенов с учётом второго прохода.

На Маке whisper считает процессором. У CTranslate2 нет бэкенда Metal, видеокарту Apple он не задействует — это свойство движка, а не настройка. На Windows с NVIDIA замер дал x27 к реальному времени.

`--hotwords` — только для чистой записи одного голоса: на тихой или групповой записи whisper подменяет неразборчивую речь строкой подсказки. Без точки на конце подсказка ломает и пунктуацию — модель копирует её стиль.

Веса `large-v3-turbo` весят около полутора гигабайт, скачиваются один раз и переживают обновление плагина. Текст, вшитый в кадр видео, не распознаётся — берётся звуковая дорожка.

> [!IMPORTANT]
> Плагин читает недоверенный материал. Если среда позволяет делегирование и вы его разрешили, снимки могут обрабатывать субагенты с правом записи в рабочую папку. Иначе их читает ведущий агент. Текст на чужом снимке может выглядеть как инструкция. Контракты требуют читать его как материал, однако риск ошибочного действия сохраняется. Подробности и приватный канал для сообщений — в [SECURITY.md](SECURITY.md).

## Как устроено

`scripts/to_md.py` держит всю детерминированную часть: ветвление по расширению, реестр, разбиение снимков на батчи, подсчёт меток, решение об эскалации, детектор испорченной расшифровки (петли, титры-артефакты, провалы, дыры) с автоматическим вторым прогоном записи другим профилем. Что считается `if`-ом, модель не решает.

`skills/convert/` — скилл конвертации и два контракта для работы модели со [снимками](skills/convert/photo-contract.md) и [расшифровками](skills/convert/summary-contract.md). `skills/setup/` — установщик, собирающий список пакетов по выводу `--doctor`.
