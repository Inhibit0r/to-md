Плагин Claude Code и Codex, который превращает в markdown то, с чем агент иначе работает дорого и плохо: записи, документы и фотографии.

С to-md вы можете:

- **сфотографировать задачи с доски** и дальше решать их текстом — снимок стоит до 4 800 токенов при каждой пересылке, распознанное условие — пару сотен;
- **расшифровать созвон или лекцию** локальным whisper и получить summary, где каждый пункт помечен таймкодом;
- **вытащить текст из pdf, docx, pptx, xlsx** и полутора десятков других форматов одной командой;
- **забрать запись с диктофона Plaud** и пропустить её через тот же конвейер.

Медиа и документы считаются на вашей машине и не стоят ничего. Через модель проходят только фотографии.

## Быстрый старт

Нужен **Python 3.10 или новее**. Остальное поставит `/to-md:setup` под вашу систему.

```
/plugin marketplace add Inhibit0r/to-md
/plugin install to-md@to-md
/to-md:setup
```

В Codex — то же самое из терминала:

```bash
codex plugin marketplace add Inhibit0r/to-md
codex plugin add to-md@to-md
```

Дальше положите файлы в `in/` и вызовите `/to-md:convert`. Результат появится в `out/`.

## Что получается

Снимок задачи с доски → `out/raw/IMG_4471.md`:

```markdown
---
source: "IMG_4471.jpg"
date: 2026-08-14
type: задача
---

## Задача 14

Тело массой m = 2 кг движется по окружности радиусом R = 0,5 м
с постоянной по модулю скоростью v = 4 м/с.

Найти: модуль ускорения и силу натяжения нити в верхней точке.

---
> Не перенесено: логотип вуза, номер слайда «7/23», край соседней страницы.
```

Последняя строка — главное, что отличает этот конвертер от «перескажи мне картинку». Модель вправе **не переносить** содержимое, но не вправе его переписывать: всё, что попало в файл, стоит там как в источнике, а всё выброшенное перечислено. Удаление, которое видно, можно проверить.

Нечитаемое место помечается `[неразборчиво]`, и снимки с двумя метками и больше автоматически уходят на второй проход — более сильной моделью, с разрешением кадрировать и перепроверять.

У записей та же дисциплина: каждый пункт summary несёт таймкод `[MM:SS]`, у документов — цитату. Пункт без якоря в файл не попадает, потому что проверить его нечем.

## Что понимает на входе

| Класс | Расширения | Чем обрабатывается |
|---|---|---|
| Записи | mp4, mov, mkv, webm, avi, m4v, mp3, wav, m4a | whisper локально, `large-v3-turbo` |
| Документы | pdf, doc(x/m), ppt(x/m), pps(x/m), pot, xls(x/m/b), odt, ods, odp, rtf, epub, csv | anydoc |
| Фотографии | jpg, jpeg, png, webp, bmp, tif, tiff, heic | зрение модели, два прохода |

txt, md, html, json, xml, yaml конвертировать незачем — агент читает их напрямую, и плагин так и скажет.

## Ручки

Скилл делает всё сам, но скрипт вызывается и руками:

```bash
python scripts/to_md.py in --out out --hotwords "Чжанцзяцзе, Тяньмэнь."   # ТОЧКА В КОНЦЕ обязательна
python scripts/to_md.py --doctor            # что установлено на этой машине
python scripts/to_md.py --escalate out/raw  # снимки, которые стоит перечитать
python scripts/to_md.py --collect out       # пересобрать сводный файл
python scripts/to_md.py --selftest
```

## Что стоит знать

- **Записи и документы бесплатны, фотографии — нет.** Пачка из двадцати пяти снимков обходится примерно в 120 тысяч входных токенов. Расшифровка часовой записи не стоит ничего, кроме электричества.
- **`--hotwords` без точки на конце ломает пунктуацию.** Модель копирует стиль подсказки: список без знаков препинания даст транскрипт без знаков препинания.
- **Ничего не пересчитывается дважды.** Реестр `out/.state.json` ключуется по содержимому файла: переименовали — не пересчитается, стёрли готовый md — пересчитается, дописали в папку ещё десять снимков — обработаются только они.
- **Скорость.** Windows с NVIDIA: замер x27 к реальному времени. На Маке считается процессором — у CTranslate2 нет бэкенда Metal, это свойство движка, а не настройка.
- **Веса** `large-v3-turbo` (≈1,5 ГБ) переживают обновление плагина; путь показывает `--doctor` полем `data`.
- **pdf без текстового слоя** честно скажет «текста нет, вероятно скан» вместо пустого файла — такой документ идёт в ветку фотографий.
- **Снимок монитора дешевле заменить скриншотом** — резче и без муара.

## Как всё устроено

- `scripts/to_md.py` — вся детерминированная часть: ветвление по типу файла, реестр, разбиение на батчи, подсчёт меток. Что можно посчитать `if`-ом, модель не решает.
- `skills/convert/` — скилл конвертации и два контракта, которые субагенты читают дословно.
- `skills/setup/` — установщик, собирающий список пакетов под конкретную машину.

## Участие, безопасность, лицензия

Замечания и идеи — в [issues](https://github.com/Inhibit0r/to-md/issues), правки — обычным pull request'ом; самопроверки гоняются в CI на Linux, macOS и Windows.

Плагин читает недоверенный материал и запускает субагентов с правом писать файлы — что это значит на практике и куда сообщать о проблемах приватно, написано в [SECURITY.md](SECURITY.md).
